# 🏰 Team Fortress 2 Aptitude Test



## 🏫 Coursework for Year 13 SSD

This is a quiz designed around Team Fortress 2. It includes several types of quizzes, those being




## 🗡️ Weapons

Tests the users ability to identify weapons based on a description or fact surrounding them.

## 🧍‍♂️Classes

Tests the users knowledge of classes within TF2

## 📕 History

Tests how well the user knows the history of the game, including updates, lore, and specific details of updates

## 🔍 Guessing Game

A Wordle like game where the user must guess a weapon whilst being given hints surrounding it as they guess.
